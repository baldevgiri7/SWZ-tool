Using the ARDOT SWZ Decision Support Tool

This interactive web application is designed to assist Arkansas Department of Transportation (ARDOT) personnel in making informed decisions about deploying various Smart Work Zone (SWZ) systems. By systematically evaluating project-specific conditions against predefined criteria, this tool helps quantify the need for different technologies.

Project Information

Quick Start

Use the navigation menu to evaluate systems individually, or use the "Evaluate All Systems" feature to see all factors in a single view.

Operational Guide:

  1. Understand the Project: Before starting, ensure a thorough understanding of the project's scope, location, duration, traffic characteristics, known safety or operational issues, and geometric conditions.
  2. Evaluate Each SWZ System:
    • Select a system from the menu or choose "Evaluate All Systems".
    • For each factor, select the radio button that most accurately reflects the conditions of the specific project.
    • Scores update in real-time.
  3. Review the Summary:
    • Navigate to the "Summary & Recommendations" page.
    • Review the consolidated table and chart. Click system names for detailed descriptions.
    • Use the "Generate PDF Summary" tool to create a formal report for the project file.
  4. Make an Informed Decision:
    • The scores and recommendations are intended to support the decision-making process.
    • Always combine these outputs with professional engineering judgment, current ARDOT policies, and budget availability to arrive at the final decision.
